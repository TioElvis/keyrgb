# keyrgb - MSI Per-Key RGB Wrapper

This script is a tool designed to **simplify my workflow** when using the excellent [msi-perkeyrgb](https://github.com/Askannz/msi-perkeyrgb) library created by Askannz. 

I created it specifically to **streamline command execution and make the tool easier to interact with**. Instead of memorizing and typing out exact flags and hexadecimal codes every time I want to change my keyboard's lighting, this script lets me use fast, intuitive keywords.

## 🚀 Features

- **Quick Colors:** Natural language names to change colors instantly (e.g., `red`, `blue`, `magenta`).
- **Direct Presets:** Immediate access to native animations without typing out long parameters (e.g., `disco`, `chakra`, `roulette`).
- **Quick Disable:** A simple `disable` command to turn off the lights entirely.
- **Advanced Support:** Maintains full compatibility with the original advanced options (custom HEX codes and per-key configuration files).
